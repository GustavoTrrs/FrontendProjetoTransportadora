# TransCarga - Frontend

Este é o painel administrativo do sistema **TransCarga**, uma interface moderna e intuitiva para o gerenciamento de operações logísticas e fretes.

## 🚀 Tecnologias Utilizadas

A interface foi construída com as melhores práticas de desenvolvimento web moderno:

- **Linguagem:** TypeScript
- **Framework:** React
- **Ferramenta de Build:** Vite
- **Estilização:** CSS Moderno (Vanilla)
- **Gráficos:** Recharts para visualização de dados
- **Ícones:** Lucide React
- **Comunicação API:** Axios

## 🛠️ Funcionalidades Principais

- Dashboard administrativo com indicadores de fretes.
- Interface de login protegida para administradores.
- Listagem, criação e remoção de registros de fretes.
- Design responsivo e focado na experiência do usuário.

## ⚙️ Como Executar

1. Certifique-se de ter o Node.js instalado.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
